## About

Personal portfolio of **Anjil Adhikari**, an AI/ML engineer with experience in machine learning, NLP, computer vision, and Generative AI. Built with React and Vite, live at [anjiladhikari.com.np](https://anjiladhikari.com.np/).

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 19, Vite 7 |
| Styling | Tailwind CSS v4 |
| Animations | Framer Motion |
| Routing | React Router DOM v7 |
| Particles | tsParticles Slim |
| Icons | Lucide React |
| Email | EmailJS |
| Linting | ESLint |

## Features

- Dark / light mode toggle
- Interactive particle background (click and hover effects)
- Smooth scroll navigation
- Contact form via EmailJS
- Live visitor counter
- CV download
- Resources page with curated AI/ML links
- Fully responsive
